# Student Database Management System

A minimal, production-ready, end-to-end Student Records Management System built with **React + Vite** and **Supabase PostgreSQL**. Designed for instant, unauthenticated web database administration with full real-time CRUD capabilities, live search, and a clean black-and-white monochrome design.

---

## 🚀 Key Features

1. **Direct Web Database Portal**:
   - Zero authentication barrier. Loads straight into the Student Records Management interface.
2. **Full End-to-End CRUD**:
   - **Create**: Add new students with client & database-level validation (Register No, Name, Department, Year 1-4, Email).
   - **Read**: Live data table showing all records sorted by creation timestamp.
   - **Update**: In-place edit modal pre-filled with existing student details.
   - **Delete**: Confirmation modal to prevent accidental data loss.
3. **Realtime Database Synchronization**:
   - Subscribes to PostgreSQL database changes via `supabase.channel('realtime:students')` to instantly sync insertions, updates, and deletions across all connected clients without page reloads.
4. **Live Search & Filter**:
   - Search by Register Number or Student Name in real time with an instant clear (`X`) button.
5. **Modern Monochrome Design**:
   - Clean black-and-white theme built with high contrast, responsive cards, and clean typography.

## 📋 Database Schema & Supabase Setup

### Execute SQL in Supabase SQL Editor

Open your [Supabase Dashboard](https://supabase.com/dashboard) &rarr; Select your project &rarr; Open **SQL Editor** &rarr; Paste and execute the following SQL (also in `supabase/schema.sql`):

```sql
-- 1. Create the students table
create table if not exists public.students (
    id bigint generated by default as identity primary key,
    register_no text not null unique,
    name text not null,
    department text not null,
    year int not null check (year between 1 and 4),
    email text not null,
    created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

-- 2. Indexes for fast search and lookups
create index if not exists idx_students_register_no on public.students(register_no);
create index if not exists idx_students_name on public.students(name);

-- 3. Configure Row Level Security (RLS) for public/anon web access
alter table public.students enable row level security;

-- Policy: Allow all operations (SELECT, INSERT, UPDATE, DELETE) for anon public web client
create policy "Public full access to students"
    on public.students
    for all
    using (true)
    with check (true);

-- 4. Enable Realtime Replication for the students table
alter publication supabase_realtime add table public.students;
```

## ⚡ Quick Start

### 1. Configure `.env`
Ensure your `.env` file contains your Supabase project credentials:
```env
VITE_SUPABASE_URL=https://your-project-id.supabase.co
VITE_SUPABASE_PUBLISHABLE_KEY=your-supabase-publishable-key
```

### 2. Run Dev Server
```bash
npm run dev
```
Open **`http://localhost:7000`** in your browser.

### 3. Production Build
```bash
npm run build
npm run preview
```

## 🖥️ Screen Walkthrough & CRUD Usage

1. **Add Student**: Click **+ Add Student**, enter Register No (e.g., `21CS101`), Full Name, Department, Year (1–4), and Email. Click **Save Student**.
2. **Search / Filter**: Enter any keyword into the search bar to filter by Register Number or Name. Click `X` to clear.
3. **Edit Student**: Click the pencil icon on any student row to update their details.
4. **Delete Student**: Click the trash can icon. A modal confirms deletion before removing the row permanently.
