# Teacher Login & Student Database Management System

A minimal, production-ready, full-stack Student Records Management System built with **React + Vite** and **Supabase PostgreSQL**. Features strict Row Level Security (RLS) ensuring each teacher accesses and manages only their own student records, real-time database synchronization, deterministic Teacher ID mapping, and a clean black-and-white monochrome design.

---

## 🚀 Key Features

1. **Two-Screen Architecture**:
   - **Screen 1 (Teacher Login)**: Minimalist login screen where teachers enter their Teacher ID (e.g. `T001`) and Password. The app deterministically maps `T001` to `t001@school.edu` and authenticates via Supabase Auth.
   - **Screen 2 (Student Database)**: Protected portal offering complete real-time CRUD operations, live search filter by Register Number, responsive table layout, and immediate session termination.
2. **Row Level Security (RLS)**:
   - Supabase PostgreSQL policies strictly isolate data by `auth.uid() = teacher_id`. No teacher can view, insert, edit, or delete another teacher's students.
3. **Realtime Database Synchronization**:
   - Subscribes to PostgreSQL changes via `supabase.channel('realtime:students')` to instantly update the UI when records change.
4. **Deterministic Domain Mapping**:
   - Accepts teacher usernames or IDs (e.g. `T001` &rarr; `t001@school.edu`) utilizing `VITE_TEACHER_EMAIL_DOMAIN`.
5. **Modern Monochrome Aesthetics**:
   - Clean black-and-white theme built with custom CSS variables, sharp contrast, responsive cards, and clean typography.

## 📋 Database Schema & Setup

### 1. Execute SQL in Supabase SQL Editor

Open your [Supabase Dashboard](https://supabase.com/dashboard) &rarr; Select your project &rarr; Open **SQL Editor** &rarr; Paste and execute the following SQL (also available in `supabase/schema.sql`):

```sql
-- 1. Create the students table
create table if not exists public.students (
    id bigint generated by default as identity primary key,
    register_no text not null,
    name text not null,
    department text not null,
    year int not null check (year between 1 and 4),
    email text not null,
    teacher_id uuid not null default auth.uid() references auth.users(id) on delete cascade,
    created_at timestamp with time zone default timezone('utc'::text, now()) not null,
    constraint unique_teacher_student_register_no unique (teacher_id, register_no)
);

-- 2. Create performance indexes
create index if not exists idx_students_teacher_id on public.students(teacher_id);
create index if not exists idx_students_register_no on public.students(register_no);

-- 3. Enable Row Level Security (RLS)
alter table public.students enable row level security;

-- 4. RLS Policies
-- SELECT Policy
create policy "Teachers can select own students"
    on public.students for select to authenticated
    using (auth.uid() = teacher_id);

-- INSERT Policy
create policy "Teachers can insert own students"
    on public.students for insert to authenticated
    with check (auth.uid() = teacher_id);

-- UPDATE Policy
create policy "Teachers can update own students"
    on public.students for update to authenticated
    using (auth.uid() = teacher_id)
    with check (auth.uid() = teacher_id);

-- DELETE Policy
create policy "Teachers can delete own students"
    on public.students for delete to authenticated
    using (auth.uid() = teacher_id);

-- 5. Enable Realtime Replication
alter publication supabase_realtime add table public.students;
```

### 2. Create the Test Teacher Account

In the Supabase Dashboard:
1. Navigate to **Authentication** &rarr; **Users**.
2. Click **Add user** &rarr; **Create user**.
3. Enter:
   - **User Email**: `t001@school.edu`
   - **Password**: `Teacher@123`
   - **Auto Confirm User?**: Check **Yes** (to bypass email confirmation).
4. Click **Create User**.

## ⚡ Quick Start & Setup

### 1. Clone & Configure Environment

```bash
git clone https://github.com/bhavyahansika/APP_DB_BHAVYA.git
cd "APP DB"
```

Configure `.env` with your Supabase credentials:
```env
VITE_SUPABASE_URL=https://your-project-id.supabase.co
VITE_SUPABASE_PUBLISHABLE_KEY=your-supabase-publishable-key
VITE_TEACHER_EMAIL_DOMAIN=school.edu
```

### 2. Install & Run Dev Server

```bash
npm install
npm run dev
```

Visit **`http://localhost:7000`** in your browser.

### 3. Production Build & Preview

```bash
npm run build
npm run preview
```

## 🖥️ Screen Walkthrough & CRUD Usage

### Screen 1: Teacher Login
1. Open `http://localhost:7000`.
2. In the **Teacher ID** field, type `T001`. (The helper text dynamically indicates the target email `t001@school.edu`).
3. In the **Password** field, type `Teacher@123`.
4. Click **Sign In**.

### Screen 2: Student Management Portal
- **Create (Add Student)**: Click the **+ Add Student** button, enter the student's Register Number (e.g. `21CS101`), Full Name, Department, Year (1-4), and Email. Click **Save Student**.
- **Read (View & Search)**: The student table lists all students assigned to your teacher ID. Use the search bar to filter by Register Number instantly with one-click clear (`X`).
- **Update (Edit Student)**: Click the pencil icon on any student row, adjust their department, year, or name, and click **Update Student**.
- **Delete (Remove Student)**: Click the trash can icon. A confirmation dialog will prompt you to verify the deletion before permanently removing the record.
- **Logout**: Click the **Logout** button in the top navbar to securely clear the session and return to Screen 1.

## 🔧 Troubleshooting

| Issue | Cause | Solution |
| :--- | :--- | :--- |
| `Invalid login credentials` | Wrong password or user not created in Supabase | Verify user `t001@school.edu` is created and confirmed in Supabase Auth &rarr; Users. |
| `new row violates row-level security policy` | Inserting with an unauthenticated session or mismatched `teacher_id` | Ensure user is logged in. The app automatically populates `teacher_id: auth.uid()`. |
| `duplicate key value violates unique constraint` | Student with this Register Number already exists under this teacher | Check if the student was already registered. Use the search bar to locate them. |
| Realtime updates not reflecting | Realtime not enabled on `public.students` table | Run `alter publication supabase_realtime add table public.students;` in Supabase SQL Editor. |
